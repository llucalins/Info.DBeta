# 🎓 Informática Descomplica

**Desenvolvido por Lucas Virginio**

Uma aplicação web moderna e interativa para ensinar informática básica de forma simples e acessível para todas as idades.

## ✨ Características

- 🎯 **4 Módulos Interativos**: Mouse, Digitação, Pastas e Botão Direito
- 🎨 **Design Moderno**: Interface responsiva com animações suaves
- 🔊 **Síntese de Voz**: Feedback auditivo para melhor acessibilidade
- 🌙 **Modo Escuro**: Tema adaptável às preferências do usuário
- 📱 **Totalmente Responsivo**: Funciona em desktop, tablet e mobile
- 🏆 **Sistema de Progresso**: Acompanhe seu desenvolvimento
- 💾 **Persistência Local**: Seus dados são salvos automaticamente

## 🚀 Tecnologias Utilizadas

- **React 18** - Framework principal
- **TypeScript** - Tipagem estática
- **Vite** - Build tool rápida
- **Tailwind CSS** - Estilização moderna
- **Framer Motion** - Animações fluidas
- **Lucide React** - Ícones bonitos
- **React Hot Toast** - Notificações elegantes

## 📦 Instalação

1. **Clone o repositório**
   ```bash
   git clone https://github.com/seu-usuario/informatica-descomplica.git
   cd informatica-descomplica
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Execute o projeto**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador**
   ```
   http://localhost:3000
   ```

## 🎮 Como Usar

### Módulo 1: Mouse 🖱️
- **Clique Esquerdo**: Aprenda a clicar uma vez
- **Duplo Clique**: Pratique cliques duplos rápidos
- **Arrastar e Soltar**: Mova elementos pela tela
- **Rolagem**: Use a rodinha do mouse

### Módulo 2: Digitação ⌨️
- **Copie Frases**: Pratique digitando textos
- **Estatísticas em Tempo Real**: Velocidade e precisão
- **Diferentes Dificuldades**: Do básico ao avançado
- **Feedback Visual**: Correção instantânea

### Módulo 3: Pastas 📁
- **Explorador Simulado**: Navegue entre pastas
- **Criar e Editar**: Arquivos e pastas
- **Interface Familiar**: Similar ao Windows Explorer
- **Persistência**: Seus arquivos ficam salvos

### Módulo 4: Botão Direito 🖱️
- **Menu de Contexto**: Aprenda as opções
- **Diferentes Itens**: Arquivos, pastas, imagens
- **Ações Comuns**: Copiar, colar, excluir
- **Feedback Interativo**: Escolha e veja o resultado
