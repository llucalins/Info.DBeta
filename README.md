# 🎮 Informática Descomplica - Treinador Interativo

Um aplicativo educacional completo para ensinar conceitos básicos de informática de forma interativa e divertida. Ideal para uso em sala de aula, com suporte para projetor e interação dos alunos.

## ✨ Funcionalidades Principais

### 🖱️ **Treinador de Mouse**
- Exercícios práticos para melhorar a coordenação com o mouse
- Diferentes níveis de dificuldade
- Feedback visual em tempo real

### ⌨️ **Treinador de Digitação (Melhorado)**
- **4 módulos especializados:**
  - **Conceitos Básicos**: Termos importantes de informática
  - **Frases de Tecnologia**: Frases sobre computadores e internet
  - **Comandos e Atalhos**: Atalhos úteis do computador
  - **Texto Informativo**: Parágrafos sobre tecnologia
- Sistema de sequência (streak) para motivar os alunos
- Feedback visual imediato (✅ correto, ❌ incorreto)
- Estatísticas em tempo real (WPM, precisão, tempo, sequência)
- Conteúdo focado em informática

### 📁 **Explorador de Arquivos**
- Simulação de navegação em pastas
- Exercícios de organização de arquivos
- Interface intuitiva para aprender estrutura de diretórios

### 🖱️ **Treinador de Botão Direito**
- Prática com menu de contexto
- Diferentes tipos de arquivos e ações
- Aprendizado de funcionalidades avançadas

### 🧠 **JOGO DA MEMÓRIA (NOVO!)**
- **12 pares de conceitos** de informática para memorizar
- **Termo + Definição**: Encontre os pares correspondentes
- **Sistema de pontuação**: Conta jogadas e tempo
- **Recordes pessoais**: Salva melhores pontuações
- **Conceitos incluídos:**
  - Mouse, Teclado, Monitor, CPU
  - Internet, Arquivo, Pasta, Software
  - Hardware, Navegador, Email, Download
- **Perfeito para projetor**: Interface clara e visível
- **Interação dos alunos**: Podem jogar no seu PC enquanto você projeta

## 🎯 Como Usar em Sala de Aula

### **Modo Projetor + PC**
1. **Projetor**: Abra o aplicativo no projetor para todos verem
2. **Seu PC**: Use o mesmo aplicativo para controlar e demonstrar
3. **Alunos**: Podem vir ao seu PC para interagir com os exercícios

### **Sequência Recomendada**
1. **Mouse** → Conceitos básicos de navegação
2. **Digitação** → Vocabulário e comandos de informática
3. **Pastas** → Organização de arquivos
4. **Botão Direito** → Funcionalidades avançadas
5. **Memória** → Revisão e consolidação dos conceitos

### **Dicas para Professores**
- Use o **Jogo da Memória** como atividade de revisão
- Deixe os alunos jogarem no seu PC em grupos
- Use as estatísticas para acompanhar o progresso
- O sistema de sequência motiva os alunos a continuarem

## 🎮 Jogo da Memória - Detalhes

### **Como Funciona**
1. Clique em "Iniciar Jogo"
2. Encontre pares de cartas (termo + definição)
3. Complete todos os 12 pares
4. Tente bater seu recorde de jogadas e tempo

### **Conceitos Educacionais**
- **Memorização**: Ajuda a fixar conceitos
- **Associação**: Liga termos às suas definições
- **Concentração**: Desenvolve foco e atenção
- **Competição saudável**: Sistema de recordes

### **Uso Pedagógico**
- **Revisão**: Após ensinar os conceitos
- **Avaliação**: Teste informal de conhecimento
- **Motivação**: Gamificação do aprendizado
- **Colaboração**: Alunos podem jogar em grupos
